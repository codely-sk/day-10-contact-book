# Day 10 – Contact Book 📒

## About the Project
The Contact Book is a Python program that helps users manage contact details. Users can add contacts, view all saved contacts, search by name, update phone numbers, and delete contacts.

## Features
- Add new contacts
- View all saved contacts
- Search for contacts by name
- Update phone numbers
- Delete contacts
- Handle invalid menu choices

## Concepts Used
- Dictionaries
- Functions
- `while` loops
- `if-elif-else` conditions
- `for` loops
- Dictionary methods like `.items()`
- String methods like `.lower()`
- `return` and `del`

## What I Learned
- How to store contact details using dictionaries
- How to search for contacts without case sensitivity
- How to add, update, and delete dictionary entries
- How to divide a program into separate functions
- How to create a menu-driven Python application

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `day_10_contact_book.py`.

## Note
Contacts are stored temporarily and disappear when the program closes.
